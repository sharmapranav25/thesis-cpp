Controller MVP v4

MVP v4 is implemented, but this experiment does not demonstrate useful target recognition or a primary-test benefit from collection diversity. On 999 scored SimpleCaptcha images, diverse and hybrid training both achieve 0% exact accuracy; single-scheme training averages 0.05%. Diverse training reduces character errors versus hybrid, but essentially ties single-scheme training. DarkBay and a supplementary CryptBB check show small character-error improvements with very low whole-CAPTCHA accuracy. City has no verified answers. These results do not disprove the broader diversity idea: the current selector retains only one cursive font for SimpleCaptcha, and synthetic validation accuracy remains around 35–40%.

80 saved renderer configurations: 16 per target family. Shared training adjustments leave 77 distinct effective profiles: 13 for SimpleCaptcha and 16 for each other family. Sampling is balanced over the original slots, so collapsed SimpleCaptcha slots upweight their matching profiles. Selection uses unlabeled target pixels, appearance similarity and diversity. Synthetic mask truth screens out generated samples where predicted localization breaks. No target masks or answers enter selection. No VLMs.

Three pooled-family training arms: hybrid-only, single eligible controller configuration per family, and a balanced collection of 16 per family. Each gets 12,800 images, the same synthetic transcripts, 20% identical clean anchors, the same common 1,600-image synthetic validation set, two matched initialization seeds and 20 epochs per seed. Transcript lengths 2–8 and the generic 62-character alphabet are shared, independent of target answer statistics.

Shared recognition curriculum: line layout, compatible full-alphabet fonts, native height 64 before 192×48 reader resizing. All arms retry together when a generated transcript loses characters; after 10/20 failed seeds, all receive 1/2 extra pixels of stroke. The hybrid arm therefore includes these common repairs. It is not an untouched replay. Repair counts and effective configuration counts.

All six readers and preregistered target predictions were frozen before answer annotations were opened. Primary evaluation: 1,000 Kaggle images reserved, 999 scored; one irregular filename annotation was excluded before scoring. Public dataset answers use original archive filename stems matched by decoded-pixel hash; DarkBay uses the original labeled directory. City and the 24 CryptBB diagnostic images have no verified answers. The separate CryptBB labeled check was added afterward with the same frozen readers. Exact accuracy is case-sensitive; CER includes insertions/deletions/substitutions. Bootstrap intervals resample images while averaging two fixed seeds; they do not measure broad seed variability. When neither arm has successes, a degenerate zero interval does not establish equivalence.

Dataset provenance: SimpleCaptcha publisher · Outlined publisher. Filename annotations are accepted as supplied, without human or OCR re-annotation.
