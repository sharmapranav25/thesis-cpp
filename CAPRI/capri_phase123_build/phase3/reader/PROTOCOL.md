# Official CAPRI Phase 3 — City reader comparison 01

This is synthetic reader training → frozen real-fit scheme estimation → a separate targeted synthetic dataset. It supersedes historical count-only definitions. Historical optional image/refinement experiments are outside official Phase 3 and remain preserved. Final production-recognizer training is excluded.

Input: city_capri_v3_variable_2to8_100k. Full new rehash passed 100,000 unique pixels and metadata labels/visibility. All 35 fonts remain in the source; three hash-selected font families (Noto Serif, IBM Plex Serif, Anton) are excluded from model fitting and retained as a heldout-font test. Training retains 32 fonts and mixed typography. Text SHA256 partitions yield 61,691 training, 6,011 selection, 4,710 calibration, 4,648 ordinary test, 1,373 font test, and 21,567 excluded font records. Exclusion avoids both text and font leakage. Case groups all covered; exact counts in data/audit.json.

All 1,599 real fit and 400 real validation file and decoded-pixel hashes match the historical split; disjoint pixels verified. Filenames are image locators only. No independently verified real transcription labels were supplied; do not call distributions accuracy. These are exposed historical development splits, not untouched tests.

CRNN from the local PARSeq model hub (CNN + two bidirectional LSTMs + CTC); SVTR tiny from OpenOCR (local/global patch mixing + CTC); PARSeq adapted to 192 dimensions and six encoder layers, upstream six permutation objective and AR/refinement decoding. Random initialization only; no pretrained recognition weights. Shared RGB 32×192, 62 case-sensitive symbols, batch128, ten complete training epochs, AdamW 0.0003, weight decay .01, 10% warmup then cosine decay, gradient clipping5, AMP float16 (float32 CTC). This is matched image/update exposure, not equal FLOPs or paper reproduction. Record actual parameters, time and steps. One seed731 is an exploratory comparison, not robust architecture ranking.

Each architecture has identical seed/data/order with and without auxiliary loss. Both instantiate the same heads to preserve initialization; plain heads are untrained/unused. Auxiliary losses: .25 cross-entropy over counts2–8 and .25 binary cross-entropy for digit/lower/upper presence. Groups are multi-label. Recognition objective remains primary. Decode up to12 characters without a known target length. Count-head support remains2–8 and cannot rule out other real lengths.

Select checkpoints by lowest synthetic selection CER, then highest exact accuracy. Calibrate count and group head temperatures only on independent synthetic calibration text. Confidence bins report synthetic reliability, not real calibration. Report CER, exact text/count accuracy, per-length and multi-label precision/recall/F1. Tests: ordinary, heldout fonts, and fixed horizontal-compression/padding stress; the latter is a transformed-image layout test, not a repaired independent-layout renderer. Tests do not select checkpoints. Freeze weights before any real inference and verify SHA256 unchanged afterwards.

The renderer retains constant occupied span and count-dependent spacing/width. A metadata ExtraTrees probe scored 100% heldout count accuracy (majority17.23%; center-gap importance94.9%). Metadata uses known synthetic glyph boxes; this is shortcut evidence, not image-reader performance. No shortcut-resistant count claim is permitted. Original corpus is preserved. Strong image count-head results must be interpreted with this limitation.

Scheme: select plain/aux per architecture on synthetic selection only; retain each architecture's fit histogram, text/group disagreement and every auxiliary count crosscheck. Equal architecture weights are an explicit aggregation choice, not an independence assumption. Save joint length/group distribution. Keep all62 characters. Preserve20–80% broad prior mass as an engineering uncertainty safeguard based on disagreements/out-of-support decodes. No fixed length or unsupported character exclusions. Bootstrap intervals measure image sampling variability conditional on models, not correctness. A minimum synthetic reading gate (each selected model calibration CER≤.35 and exact≥.20) blocks automatic use of failed readers; it does not prove real transfer. Inspect systematic disagreements before generation.

Final generation is a subsequent step of this same Phase3 task, after comparison and inspection. It uses frozen CAPRI City profile, all35 fonts and broad typography, optional refiners off, a new output directory and full image/label/hash/visibility/coverage audit. No final-dataset completion claim until audit passes.
