Does the hybrid starting point help?

The hybrid starting bank won 14 of 15 paired diagnostic comparisons under both the DINO objective and the separate legacy appearance comparator. Random seed 60303 won on DarkBay under both metrics; random did not win on average across the three seeds for any family. This is evidence that the hybrid usually helps this controller, not that it always helps. Visual matches remain incomplete. The result is limited by the controller's inability to change inherited charset, layout, slant and size jitter, small fit/selection batches, three random banks and previously exposed diagnostic targets. It does not establish recognition accuracy or superiority of hybrid initialization for a fully controllable renderer.

Choosing a start: Post-hoc analysis of the existing selection scores: taking the lowest score across all four runs would choose hybrid for City, CryptBB, DarkBay and Outlined, and random 60202 for SimpleCaptcha. That misses the winning DarkBay random run and picks a worse SimpleCaptcha run. No oracle seed selection was used in the main galleries. Multiple starts alone are not a demonstrated deployable improvement; selection needs stronger validation.

Same frozen DINO attention controller, renderer and target pixels. Per run: 192 fit candidate slots × 4 renderings, 16 selection slots × 8 renderings, then 24 diagnostic samples. Three generic random banks per family versus one fixed hybrid bank. Same renderer seeds, font proposal subset and search RNG. Score calibration uses a separate random bank shared by all arms.

Random banks contain no hybrid predictions; only canvas dimensions come from target fit pixels. Generic text specs draw independent fonts, character groups, geometry and effects. This tests replacing the entire starting recipe bank. It also exposes fixed inherited settings: the current controller cannot directly change charset, layout, slant or size jitter. It is not a pure initialization comparison in a fully controllable parameter space.

Lower score means closer under this DINO comparator, with penalties for incomplete/unusable renders. Previously exposed diagnostic targets; no target answers, OCR or VLM. No reader trained. Three seeds do not establish statistical certainty or an “always” claim. Blank render failures, if any, count against validity and stay visible.
