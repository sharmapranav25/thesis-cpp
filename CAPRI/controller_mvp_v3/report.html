Controller MVP v3 — no VLMs

Pixels → frozen hybrid starting labels → predicted text masks → typography/background comparison → renderer search.

Added a synthetic-trained U-Net, hole/stroke/contrast descriptors, and search over all 38 sampled effects. No target answers, boxes, masks, font identities or source recipes enter the controller. Existing font bank retained; no target-library fonts imported.

Synthetic mask validation

512 validation images using font families excluded from the new model's 4,096-image training split. Mean mask IoU: 50.0% → 70.0%. Hollow text plus interference: 25.4% → 57.4%. These are synthetic results; real target mask accuracy is unknown.

Evaluation boundaries

The three paired search arms rank the same 96 candidate renders. Full v3 adds search candidates and renderer freedom, so its benefit cannot be attributed to one change alone. Controls are selected on fit/selection images and frozen before evaluating these test images.
