Controller 2: DINO attention

Built: 79 retained profiles across five families. Visual outcome: partial for City, CryptBB and DarkBay; failed for Outlined and SimpleCaptcha. No family-match pass.

DINO distance improves22–39% over the hybrid starts on reused diagnostic pixels, but this does not establish better typography or recognition. Synthetic attention/text IoU is only0.10–0.24. The separate legacy comparator favors Controller1 on every family and flags DINO regressions versus hybrid for DarkBay and Outlined. Attention selects different controls from CLS-only on four families, yet does not consistently improve either independent measurements or visual quality. No new solver was trained.

The79 archives have79 distinct render signatures on three fixed recipes each. This finite probe is not proof of global diversity. Both controllers remain available independently.

Same goal as Controller 1: improve text and background resemblance from unlabeled target pixels, starting with the frozen hybrid. Different underlying comparison model: official frozen DINO ViT-S/8. No VLMs, OCR, target strings, boxes, masks or texture labels enter this controller.

DINO supplies six attention heads and patch embeddings. The search compares global appearance, attended and complementary regions, layout and color distributions. Attention is saliency, not calibrated text localization. All font and effect choices come from the existing generic renderer.

Selection uses fit/selection pixels only. The displayed test pixels were exposed in earlier MVPs: these are diagnostic comparisons, not a fresh generalization claim. DINO's own lower score does not establish recognition improvement. The CLS-only selector shares the DINO-guided proposal pool. Controller 1 used a different earlier search budget.

No new reader was trained in this iteration. Synthetic completeness/usability and attention overlap are diagnostics, not target solving accuracy. Original and generated strings differ.

City

Some samples have cleaner interference and a more pixelated digit appearance than the hybrid start. Several generated backgrounds remain colored or dark while the targets are pale gray/white; font weight and digit shapes still differ. Attention covers both digits and background lines. The lower DINO distance is a partial signal, not a family-match pass.

Clear visual failure despite a lower DINO distance. The selected controller produces thin fragmented script-like text instead of the target's large outlined glyphs. SimpleCaptcha

DINO selects Sanchez/Dokdo rather than Controller 1's cursive Great Vibes, and removing resampling restores some synthetic glyphs. It still misses the target's per-character square frames, pale background consistency, placement and regular glyph count. Some outputs remain tiny and cluttered. The existing renderer has no explicit per-character frame control. No family-match pass; the attention selector does not outperform CLS-only on this diagnostic DINO score.
