# CAPRI thesis chapter bundle

Read `chapter.html` in a browser. Edit `chapter.md`. The draft covers the initial feature-bank pilots and three-feature 10 × 3 classifiers through multi-view specialists, CNN/transformer comparisons, joint mapping, CAPRI, font variety and Meta-Sim-inspired adaptation. Failed gates, abandoned image refiners and limitations are retained.

- `references.bib`: 16 primary-method references, with the same R1–R16 keys as the chapter. Two long author lists use BibTeX `and others`; expand from publisher metadata if the university requires full lists.
- `evidence_index.html` / `.md`: chapter-to-experiment source map.
- `evidence_manifest.json`: original paths, copied-source hashes and snapshot time.
- `evidence/`: frozen local documentary evidence; old statements remain historical rather than silently rewritten.
- `assets/`: original experiment figures used in the visual appendix.
- `dataset_status_snapshot.json`: dated operational snapshot, not a live dashboard.
- `build_report.json` and `html_validation.json`: build and rendering checks.

This is a detailed research draft, not a final independently audited publication. It does not claim real-feature accuracy without annotations, pristine evaluation on repeatedly inspected families, full Meta-Sim reproduction, or downstream OCR gains. A separate recognition-training process may exist in another project; its results are outside this chapter's verified evidence.

The chapter is self-contained for reading. Keep the `assets` directory alongside the HTML. Evidence links resolve within this bundle. The builder uses recorded original paths and should only be rerun intentionally: doing so updates the evidence snapshot. Historical experiments and frozen releases were not edited to make the chapter.

The HTML is printable from a browser; no pagination-verified PDF or Word document is claimed in this delivery.
