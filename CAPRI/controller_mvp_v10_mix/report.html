Mixed custom and DINO controller

Two frozen comparators score every candidate: custom mask/typography features and DINO v2 features, calibrated equally. Search mixes text/background settings and mutates the resulting recipes. Target input is unlabeled pixels only; no VLM or target strings.

Profiles are selected using two separate validation batches and a renderer-usability gate. Diagnostic targets were previously exposed. Existing controllers had different original budgets; the mixture receives extra search. Component scores are optimization criteria, not independent proof of family resemblance or solver transfer.

The same-pool selector arms isolate how each comparator chooses from the shared shortlist. The shortlist includes mixture-guided mutations, so this is a selector comparison rather than an equal-budget end-to-end retraining benchmark.
